# 约 2 分 30 秒演示流程

视频包含实际浏览器操作和中文讲解字幕，无配音。时间以视频实际帧时长为准。

| 时间范围    | 展示                               | 解释重点                                 |
| ----------- | ---------------------------------- | ---------------------------------------- |
| 00:00—00:25 | 首页、空输入提示、进入示例         | 独立店主、无需登录、解决素材到表达的问题 |
| 00:25—00:50 | 三张素材、商品/价格/特点、确认事实 | 素材用途与事实先由人确认，未知信息不编造 |
| 00:50—01:10 | 一次模拟失败、保留输入重试         | 异常可恢复，不要求从头填                 |
| 01:10—01:45 | 三段脚本、只改开头、撤回、手动编辑 | 结果不理想时提供具体操作，其他内容保持   |
| 01:45—02:15 | 播放分镜、保存、刷新恢复           | 预览不是成片，草稿是本机文字记录         |
| 02:15—结束  | 导出拍摄小笺、完成后行动及补充回归 | 交给剪辑、返回修改、再做一条；不自动发布 |

手动演示异常：确认事实页展开“演示设置”，勾选一次失败，再生成；失败后点重试。

结果不理想：修改一段文字或单独改写，再撤回；检查其他两段不变。

离线备份：直接用现代浏览器打开 demo/index.html，无需安装依赖。output/screenshots 中包含进入、素材、确认、失败、结果、交接、小屏截图；即使网页或视频不可访问，也可对照上述流程说明验收。
